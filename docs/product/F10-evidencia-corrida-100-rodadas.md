# F10 — Evidência: 100 rodadas de corrida de CPF no PUT /api/v1/clientes/{id}

Teste temporário (removido depois da execução), MySQL 8.4 via Testcontainers, duas edições simultâneas por rodada para o mesmo CPF (clientes diferentes). Comando:

```
apps/api/mvnw -f apps/api/pom.xml verify -Dtest=NONE -Dit.test=ClienteAtualizarIT#TEMP100 -Dsurefire.failIfNoSpecifiedTests=false
```

Resultado: 100 de 100 rodadas com um 200 e um 409, nenhuma resposta 5xx.

Limites: a tabela do CRIVO registrou 99 de 100 numa execução anterior, e esse número continua na PR. O deadlock real do MySQL não foi provado (`lock_deadlocks=0`); o 409 de deadlock só é testado com exceção simulada. Esta execução não substitui aquele número.
